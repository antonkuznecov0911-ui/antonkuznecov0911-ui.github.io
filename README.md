Coffee Shop App created with Flutter/Dart. A customer can order coffee (with images and prices displayed). The ordered coffee is added to a separate order page. When coffee is ordered, the message "Successfully added to cart" appears. When items are removed from the shopping cart, the message"Item removed from the cart" appears. The App features an adaptive design that fits screens of any width and height. The elements which are placed vertically can be scrolled down, so they all fit nicely.
